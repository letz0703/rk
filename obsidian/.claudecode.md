# Claude Code: Obsidian Wiki Rules

## Vault Structure (Zettelkasten 3-Layer)
- `01_Inbox/` — 웹 클립 원본 도착지. 정제 전 raw 데이터.
- `02_Notes/` — 정제된 영구 노트. 개념 단위, 재사용 가능.
- `03_Projects/` — 진행 중 프로젝트 노트 (rainskiss, kiss 등)
- `04_System/` — 템플릿, 에셋, 스크립트

## YAML Frontmatter (필수)
모든 노트는 아래 frontmatter를 포함해야 한다:
```yaml
---
created: YYYY-MM-DD HH:mm
updated: YYYY-MM-DD HH:mm
tags: [category, status]
source: "source_url_or_info"
---
```

## 명명 규칙
- `02_Notes/` 파일명: lowercase + hyphens (e.g., `suno-prompt-guide.md`)
- `01_Inbox/` 파일명: 날짜 prefix (e.g., `2026-05-18-clip-title.md`)
- `03_Projects/` 파일명: 프로젝트명 그대로

## Wiki 링크
- 모든 개념 연결은 `[[Note Name]]` 형식 사용
- 새 노트 작성 시 관련 기존 노트에 backlink 확인

## 워크플로우 명령

### Inst (클립 → Inbox)
웹 클립 입력 → YAML frontmatter 추가 → 핵심 개념 WikiLink 처리 → `01_Inbox/`에 저장

### Lint (Vault 정리)
- `01_Inbox/` 스캔 → frontmatter 누락 파일 수정
- broken [[link]] 탐지 → 수정 제안
- orphan 노트 태그 제안
- 정제 가능한 노트 → `02_Notes/` 이동 제안

### Query (컨텍스트 합성)
- `02_Notes/` + `03_Projects/` 기반 요약
- 현재 진행 상황 + 권장 다음 액션 3개 출력

## 정리 기준 (rainskiss 도메인)
포함: AI 콘텐츠 제작, 창작 기법, 음악/비주얼 레퍼런스, 시대별 문화 아카이브
제외: 개인 민원, 빌라 갈등 자료
